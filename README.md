# 🏦 Simple Banking Console Application (Python)

A clean and beginner-friendly **console-based banking application** built entirely with core Python fundamentals.  
The project uses **lists and dictionaries** for in-memory data storage, making it ideal for learning, assignments, and introductory programming practice.

---

## 🚀 Features

### ➤ Create Account
- Enter **name**, **4-digit PIN**, and **initial deposit**.
- System automatically generates a unique **Account Number**.
- Account is stored as a dictionary inside a list.

### ➤ Login
- Secure login using **Account Number + PIN**.
- Validates incorrect credentials with friendly error messages.

### ➤ Check Balance
- Displays current balance formatted in **PKR**.

### ➤ Deposit Money
- Accepts any positive amount and updates account balance.

### ➤ Withdraw Money
- Validates sufficient balance before allowing withdrawal.

### ➤ Transfer Funds
- Transfer money to another account using their account number.
- Validates both account existence and available balance.

### ➤ Logout
- Returns the user safely back to the main menu.
